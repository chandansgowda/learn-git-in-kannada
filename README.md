## 🤔 Why this exists

Most Git tutorials are in English, and many beginners get lost in the first 10 minutes.
This project explains Git the way you'd explain it to a friend, in the language you think in.

## 🧭 Your learning path

| Step | Topic | What you'll be able to do |
|------|-------|---------------------------|
| 1 | What is Git? | Understand why every developer uses it |
| 2 | Install & setup | Get Git running on your computer |
| 3 | Your first repo | `git init`, `add`, `commit` |
| 4 | GitHub basics | Push your code online |
| 5 | Branches | Work on features without breaking things |
| 6 | Pull Requests | Contribute to other people's projects |

## ⚡ Quick start

```bash
git clone https://github.com/chandansgowda/learn-git-in-kannada.git
cd learn-git-in-kannada
```

Open the files in order and follow along. Type the commands yourself, don't just read them!

## 🛠️ Cheat sheet

```bash
git status          # what's going on?
git add .           # stage all changes
git commit -m "msg" # save a snapshot
git push            # send to GitHub
git pull            # get latest from GitHub
```
