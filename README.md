# learn-git-in-kannada
Your one-stop resource to learn git &amp; github from scratch in namma kannada 💛❤️

## Learner submissions

Add your name on a new line in `learners.txt` and open a pull request. The
learner workflow welcomes the author and automatically merges ready PRs that
change only this file and preserve all existing lines in order.

For conflicting submissions, the workflow combines both versions and pushes a
merge commit directly to the default branch. This does **not** go through the
normal PR merge checks or reviews; branch protection can block the push. Other
PRs and submissions that remove or edit existing lines require manual review.
The workflow needs Actions write permissions for repository contents, pull
requests, and issues. It retries open PRs periodically.
